# Third-Party Notices

This project vendors a small, pruned set of third-party header files. No
third-party libraries are linked at build time; every HIP/HSA/verbs entry point
is resolved dynamically at run time through the `dlopen`/`dlsym` wrappers under
`wrapper/`. The vendored headers provide declarations, types and `static inline`
helper functions, so some header code is compiled into the `hva` binary.

The components below retain their original license and copyright. Their license
texts are preserved verbatim in the vendored files themselves. This file must
accompany any binary distribution of `hva`.

---

  commit `37723244ca8cd75d5e55d30f44c77af1bd49218b`)
